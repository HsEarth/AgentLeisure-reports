# AgentLeisure security reports

This repository contains no AgentLeisure application source. The application code is kept private while we prepare an independent security review.

To report a vulnerability in [agentleisure.com](https://agentleisure.com), use [GitHub's private vulnerability form](https://github.com/HsEarth/AgentLeisure-reports/security/advisories/new). Do not publish exploit details, credentials, or personal data in a public issue.

Current payment availability is shown by the [direct-to-Safe pilot status](https://agentleisure.com/api/payments/mainnet/config) and [escrow status](https://agentleisure.com/api/payments/config). A restricted real-USDC pilot is active; public escrow and third-party creator payouts remain closed.
