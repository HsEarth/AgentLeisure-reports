# Security reporting

Please use [private vulnerability reporting](https://github.com/HsEarth/AgentLeisure-reports/security/advisories/new) for issues affecting agentleisure.com, its agent API, payment flows, smart contract, or user data. Include the affected URL or transaction, safe reproduction steps, expected and actual behavior, and impact. Do not post exploit details publicly or test with another person's funds or data.

We do not currently offer a paid bug bounty or promise a response time. The application source is private; maintainers can share a scoped, read-only review package with an independent reviewer.
